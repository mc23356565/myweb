⚙️ 发布设置

它是怎么工作的？
日记数据存放在仓库里的 data/journal.json。点「保存并发布」时，浏览器会直接调用 GitHub 的 Contents API，用一个 细粒度访问令牌（Fine-grained PAT） 把改动提交进仓库， GitHub Pages 随后自动重新部署（约 30～60 秒）。不需要服务器，也不需要数据库。
令牌怎么建： GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 只授权这一个仓库 → Repository permissions 里把 Contents 设为 Read and write → 生成后复制粘贴到这里。
